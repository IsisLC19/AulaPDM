# Aula PDM
## Contexto
Crie uma **aplicação SPA** para analisar espectro de um arquivo Mp3.

## Requisitos
1. O usuário seleciona um arquivo do seu dispositivo.
2. Executa um "play"
3. O analisador inicia a renderização dos gráficos.

## Recursos Adicionais 
1. Permita alterar a frequência de Hz da música que estiver em execução para outras frequências populares de terapia alternativa.
2. Permita salvar o arquivo com a nova frequência adicionada.
3. Permita o usuário possa selecionar a emoção atual para que tenha sugestões de música.
4. Permita fazer remix de músicas

## Stack
* Html, CSS e JS puro (Vanilla).
*  Utilize bibliotecas populares para reduzir o código, erros e manutenção.
*  Vou hospedar no Git Pages.

## UI / UX
* Mobile First 
* Interfaces minimalistas e limpas.
* Utilize tons de roxo que mudem de acordo com o Hz da música.
* Modo claro e escuro.
* Efeitos em botões e outros componentes.

## Instruções para Agentes de IA
1. Analise sempre a viabilidade do desenvolvimento.
2. Não havendo viabilidade, não execute a tarefa e solicite interação humana.
3. Todo ajuste, correção, incrementação, registre em um arquivo de baklog. Salve o arquivo em /spec/backlog.md registrando a data, a hora e a tarefa executada.
